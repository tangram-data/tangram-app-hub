# tangram-snowflake-connector

## Authentication Setup Overview

To connect Tangram with Snowflake, follow these steps:

1. **Decide which Snowflake user account Tangram will use**  
   (Ideally, create a dedicated service user for integration instead of using a personal account.)
2. **Grant the required privileges to this user**  
   The user or their active role must have the `CREATE EXTERNAL VOLUME` privilege.
3. **Log in as this user, activate the correct role, and generate a Programmatic Access Token (PAT)**
4. **Use this PAT in Tangram**  
   When setting up the Snowflake connector in Tangram, use the PAT as the password.

---

## Step 1: Create or Choose a Service User

It is recommended to use a dedicated **service user** for integrations like Tangram, rather than a personal user account.  
You can create a new user in Snowflake with:

```sql
CREATE USER tangram_service_user PASSWORD = 'yourStrongPassword123!';
```

---

## Step 2: Grant Required Privileges

Tangram requires the ability to **CREATE EXTERNAL VOLUME** in Snowflake.  
By default, only users with the **ACCOUNTADMIN** role have this global privilege.  
To use a different role, an ACCOUNTADMIN must grant the privilege to your custom role:

```sql
-- As ACCOUNTADMIN:
GRANT CREATE EXTERNAL VOLUME ON ACCOUNT TO ROLE <role_name>;
```

Replace `<role_name>` with your chosen role.  
Then assign this role to your service user:

```sql
GRANT ROLE <role_name> TO USER tangram_service_user;
ALTER USER tangram_service_user SET DEFAULT_ROLE = <role_name>;
```
For guidance on creating custom roles or modifying privileges, see the [Snowflake documentation on creating custom roles](https://docs.snowflake.com/en/user-guide/security-access-control-configure#creating-custom-roles).

---

## Step 3: Generate a Programmatic Access Token (PAT)

Log in as the Tangram service user (or whichever user Tangram will use), activate the correct role, and generate a PAT following [Snowflake’s instructions](https://docs.snowflake.com/en/user-guide/programmatic-access-tokens#generating-a-programmatic-access-token).

> **Note:**  
> The PAT should be generated by the **exact user account** and with the **role** Tangram will use to connect.  
> The user/role must have all required privileges before generating the PAT.

---

## Step 4: PAT Prerequisites and Security

Make sure all [PAT prerequisites](https://docs.snowflake.com/en/user-guide/programmatic-access-tokens#prerequisites) are met:

- **Network policy requirements:**  
  Your user or account must be covered by a network policy that allows access from the IP address(es) where PATs are generated and used.

  To assign an existing network policy to your account:
  ```sql
  ALTER ACCOUNT SET NETWORK_POLICY = my_network_policy;
  ```

  Or to a specific user:
  ```sql
  ALTER USER tangram_service_user SET NETWORK_POLICY = my_network_policy;
  ```

  [Read more about network policies in Snowflake.](https://docs.snowflake.com/en/user-guide/network-policies-intro)

- **Authentication policy requirements:**  
  Your account's authentication policy may restrict PAT usage. If so, ensure `'PROGRAMMATIC_ACCESS_TOKEN'` is included in permitted authentication methods.

  **Example:**
  ```sql
  ALTER AUTHENTICATION POLICY my_auth_policy
    SET AUTHENTICATION_METHODS = ('OAUTH', 'PASSWORD', 'PROGRAMMATIC_ACCESS_TOKEN');
  ```

**Security tips:**
- Store PATs securely and rotate them as per organizational policies.
- Never expose PATs in code repositories or logs.

---

## Using PATs in Tangram

When configuring the Snowflake connector in Tangram, supply the **PAT in the password field** (not your Snowflake login password).

---

## Using Snowflake with Tangram SQL

### Federating a Snowflake Database

To query Snowflake tables from Tangram SQL, first federate your Snowflake database by creating a catalog:
* In the Tangram SQL UI, go to Create Catalog.
* Select the Snowflake database you want to connect.

In Tangram SQL, each catalog corresponds to a Snowflake database. You can switch databases with `USE CATALOG`, for example:
```sql
USE CATALOG my_snowflake_catalog;
```

---

### Connecting to a Snowflake Warehouse

To connect to a Snowflake warehouse through a PostgreSQL client:

1. In the Tangram OS UI, navigate to:
    `Workspace > Compute > SQL Engines`.
2. Copy the SQL Engine ID of your Snowflake warehouse.
3. Connect with a PostgreSQL client using:
```
jdbc:postgresql://<your-tangram-sql-service-url>/<snowflake-warehouse-sql-engine-id>
```
